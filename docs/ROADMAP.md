# Learning and delivery checkpoints

1. Run offline demo and tests. Explain why proposals do not write.
2. Configure an API key locally; run basic and structured lessons. Inspect actual output.
3. Trace the tool loop and test a no-tool request, bad arguments and a refusal.
4. Run live calendar scenarios from EVALUATION.md. Save real results before claiming accuracy.
5. Explore chaining, routing and parallel checks. Compare latency and API call counts.
6. Run the orchestrator and inspect whether sections follow their assigned goals.
7. Improve reliability: durable transcripts, context compaction, deterministic timezone/DST validation, transactional conflicts and measured evaluations.
8. Optional portfolio extension: an investment research assistant using read-only market/document tools, source citations and deterministic financial calculations. Keep trading execution out of the learning MVP.

Future external-calendar integration needs OAuth, verified account/recipient selection, idempotency, and real API success results. It is not part of v0.1.0.
